Two findings that shape everything

The two data files are two different user populations

Both files reuse the VLUSR000001… ID scheme, but of 1,000 shared IDs, zero map to the same person. user_id is not a shared key across files — they cannot be joined, only analysed separately or re-keyed.

The entire monetisation layer is missing

Rewards ledger, wallet transactions, withdrawals and the referral lifecycle do not exist as tables, and no monetary amount field appears anywhere. Only 7 of 20 sampled KPIs are computable today — the rest wait on these proposed structures.

What the simulated data covers

The user & engagement layer is rich and internally consistent — a reliable base for the dashboard on the next tab.
